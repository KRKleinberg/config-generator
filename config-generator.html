Guide

Overview

Builds device configs from a template, entirely in the browser. Nothing leaves the page and nothing survives closing the tab; save a session to keep your progress.

Using the Tool

Files and loading
Template
The config, with {{ VARIABLE }} where values go.
Variables
Optional .vars.ini giving each field a hint, dropdown, or validation.
Auto-detect
Fields follow the template's variables automatically.
Open
(Top left, or Ctrl+O) Any file, or drop files anywhere in the window: .session.json restores a session, .ini loads variables, anything else loads as a template.
Filling out the form
Find a variable
Click a field label to jump to it in the preview (again to cycle); click a highlighted {{ VARIABLE }} to jump back to its field.
Manual edits
Template-level edits
Edits apply to the template, not the output, so {{ VARIABLE }} entries keep working; switching views commits open editors.
Reset
On a section: restores it. Above the form: clears every input; files and edits stay.
Copying and output
Auto-cleaning
!KEYWORD: badges and ! comments are stripped from output, except on free-form commands (passwords, keys, descriptions, remarks) where a mid-line ! is part of the value. Bare ! lines and banner blocks pass through.
Unfilled variables
Come out as literal {{ VARIABLE }} text.
Saving your work
Save
(Top left) Opens a menu. Session (also Ctrl+S) saves your whole workspace as one .session.json file. Template writes the template with its {{ VARIABLE }} entries intact and your manual edits baked in. Export config writes the device-ready output. Export vars writes a starter .vars.ini.

Maintaining Templates

Writing templates
Syntax Description
{{ VAR }} Substitutes a value.
{{ VAR | filter }} Filters: default('x'), upper, lower, trim.
{{ [V1, V2] | join(',') }} Joins the non-empty values.
{% if VAR %} {% else %} Branches on whether VAR is filled and must open and close within one section; there is no ==, so use a choices dropdown with one field per branch.
{# comment #} Stripped from output; may span sections but cannot nest.
!!! Section Name Starts a copyable section. !!!!! or more marks it important with a red header.
!KEYWORD: v1, v2 End-of-line badge for any all-caps keyword, e.g. !STIG: V-1234; stripped from output.
Writing vars.ini

One [VAR_NAME] section per variable with key = value lines. Names: letters, digits, underscores, dots, and hyphens; no spaces.

Key Description
description Hint under the field; \n breaks lines.
placeholder Grey example text, never submitted.
default Value prefilled into the field.
type int restricts input to digits.
choices [opt1, opt2] renders a dropdown.
regex Validation pattern in single quotes.
error Message shown when the regex rejects a value.
category Heading the field is grouped under.
required false makes the field optional.
group Fill any field in a group and all become required.

Starter file: with a template loaded and no vars file, Export vars in the Save menu writes a boilerplate .vars.ini for the template's variables.

Guide

Overview

Generates standardized network configurations entirely in your browser. Nothing is sent over the network and nothing persists after this tab closes. Save a session to keep your progress.

Using the Tool

Files and loading
Template
The configuration itself, with {{ VARIABLE }} entries where values go.
Variables
An optional .vars.ini that gives each field its hint, dropdown, and validation.
Auto-detect
Runs automatically when a template loads, building a form field for every variable it finds. Auto-detected fields have no hints, dropdowns, or validation. If a .vars.ini exists for your template, load it. Click it to re-detect after editing the template; new variables do not appear on their own.
Drag and drop
Drop files anywhere on the form panel: .session.json restores a session, .ini loads variables, anything else loads as a template.
Filling out the form
Find a variable
Click a field label to jump to that variable in the preview; click again to cycle through each place it appears. Click any highlighted {{ VARIABLE }} in the preview to jump back to its input field.
Linked groups
If any field in a linked group is filled, the whole group becomes required.
Manual edits
Template-level edits
Edits apply to the template text, not the final output: {{ VARIABLE }} entries keep working inside an edited section and form changes still flow through. You can even add a new variable and click Auto-detect to get a field for it.
Reset
On an edited section: restores that section's template output. Above the form: clears every input AND reverts all manual edits at once. Loaded files stay.
Copying and output
Auto-cleaning
!KEYWORD: badges and ! comments are stripped from copied and saved text. A bare ! line passes through to answer device prompts; banner blocks are left untouched.
Unfilled variables
Come out as literal {{ VARIABLE }} text. Fill every amber variable before pasting to a device.
Saving your work

Three save buttons, three different files:

Save Config
(Top right) The finished, device-ready configuration.
Save Template
(Top right) The template itself, with its {{ VARIABLE }} entries intact and your manual edits baked in. Use it to make a recurring edit permanent or to hand changes back to the template maintainer.
Save Session
(Top left) Your whole workspace: loaded files, form inputs, and manual edits, saved as one .session.json file. This is the only way progress survives closing the tab.

Maintaining Templates

Writing templates
Syntax Description
{{ VAR }} Substitutes a value.
{{ VAR | filter }} Supported filters: default('x') , upper , lower , trim .
{{ [V1, V2] | join(',') }} Joins the non-empty values.
{% if VAR %} {% else %} Branches on whether VAR is filled. Existence checks only. There is no == comparison; use a choices dropdown and one field per branch instead. An if block must open and close within one section.
{# comment #} Stripped from output. May span section markers; cannot nest.
!!! Section Name Splits the preview into copyable sections. Five bangs ( !!!!! ) render the header in red for critical sections.
!KEYWORD: v1, v2 End-of-line colored badges (e.g., !STIG: V-1234 ). Any all-caps keyword works; badges are stripped from output. End of line only.
Writing vars.ini

One flat [VAR_NAME] section per variable, with key = value lines below it. Unrecognized keys are ignored with a warning. Variable names may contain letters, digits, underscores, and hyphens. Spaces are not allowed.

Key Description
description Hint shown under the field. \n and \t insert line breaks.
placeholder Grey example text. Never submitted.
default Real value prefilled into the field.
type int restricts input to numbers.
choices [opt1, opt2] renders a dropdown. Inline list only.
regex Validation pattern, wrapped in single quotes.
error Message shown when the regex rejects a value.
category Heading the field is grouped under in the form.
required false makes the field optional.
group If any field in a group is filled, all become required.

Starter file: run Auto-detect with no variables file loaded, then click the download icon beside it to export a boilerplate .vars.ini covering the template's variables. Fill in the hints and validation by hand.
